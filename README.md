# The Below

The Below is an open-source Minecraft mod focused on exploration, progression and mystery.

The project introduces a new dimension hidden beneath the Void, designed to feel like a natural extension of Minecraft while offering a completely different environment to explore.

## Planned Features

- A new underground dimension beneath the Void
- Multiple unique biomes
- New mobs and creatures
- Boss encounters
- New blocks, items and resources
- Custom structures
- Progression system
- Environmental storytelling and lore
- Exploration-focused gameplay

## Project Status

The Below is currently in early development.

The initial focus is on designing the core dimension, establishing the technical foundation of the mod and defining its progression system.

Development will happen openly on GitHub.
